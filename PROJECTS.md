# Five portfolio projects

These projects run **alongside learning**, not after all courses are finished. Each will eventually have its own GitHub repository, linked from its corresponding monthly Issue.

| # | Target | Project | Deliverables |
|---|---|---|---|
| 1 | Apr 2027 | Python Failed Login Analyzer | Sample/synthetic auth logs, Python parser, failed-login summaries, tests, README |
| 2 | Aug 2027 | Security Events Dashboard | Cleaned event data, visualizations, explanatory notes and screenshots |
| 3 | May 2028 | Mini SOC Investigation Lab | Sample log analysis, detection rules, incident timeline and report |
| 4 | Apr 2029 | Security / Fraud Analytics | Dataset provenance, exploratory analysis, baseline evaluation and visual report |
| 5 | Jun 2030 | Final Cybersecurity Capstone | Defined question, reproducible code, evaluation, report and demo |

## Minimum quality checklist

- [ ] README: problem, setup, methods and results
- [ ] No secrets, personal information or unauthorized data
- [ ] Reproducible sample dataset or safe download instructions
- [ ] Clear evidence of testing and limitations
- [ ] Commits made by the learner from her own GitHub identity
