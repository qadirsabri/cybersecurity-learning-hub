# Cybersecurity Learning Hub (2026–2030)

A practical, **month-by-month cybersecurity roadmap** for a Business Data Analytics student, starting November 2026 and ending June 2030.

**Cadence:** approximately 3–4 hours/week, with flexibility during university exams. **Focus:** security analytics, Python, SQL, logs, detection, dashboards and portfolio projects.

## Annual progression

| Period | Focus | Portfolio outcome |
|---|---|---|
| Nov 2026–Oct 2027 | Foundations, Python, Linux, web security, analytics | Failed Login Analyzer; Security Events Dashboard |
| Nov 2027–Oct 2028 | Blue-team operations, SIEM, detection, incident response | Mini SOC Investigation Lab |
| Nov 2028–Oct 2029 | Specialization, automation, SQL, certification choice | Security/Fraud Analytics Project |
| Nov 2029–Jun 2030 | Final-year capstone, documentation and career preparation | Final Cybersecurity Capstone |

**Important:** All security exercises must use authorized labs, synthetic data, or explicitly permitted datasets. No real credentials, private logs or sensitive information should be committed.

**Contribution credit:** The learner should commit using her own GitHub account and verified email. Repo ownership and individual contribution attribution are separate.
